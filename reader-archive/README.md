# Prior reader copies

These are **derived reader Markdown copies** recovered from ordinary `main` history of
[`sondreskarsten/norwegian-laws`](https://github.com/sondreskarsten/norwegian-laws).
They preserve the exact files committed immediately before one recorded repository
exit. Original source observations, source knowledge times and legal repeal dates
are **unknown**. The copies may retain errors from their original parser or formatter.

The verified archive contains **105 documents: 61 laws and 44 regulations**
(660,274 bytes). Every copy is identified by its original Git blob and SHA-256.
The exit commit is
[`b8e08232422013a96c38cdfc074618c979777458`](https://github.com/sondreskarsten/norwegian-laws/commit/b8e08232422013a96c38cdfc074618c979777458),
committed **2026-07-21 at 11:23:35 UTC**. That timestamp records a repository exit;
it does not establish when a law ceased to apply or when Lovdata changed its source.

## What the archive establishes

Every original path existed at parent commit
[`98d4e4d5d43d22384cf9c1862816bf8f57122c33`](https://github.com/sondreskarsten/norwegian-laws/commit/98d4e4d5d43d22384cf9c1862816bf8f57122c33)
and was absent at the exit commit. All 105 paths were also absent at checked main
commit `c8fba0a6bfe131883dee63d6ab702a1dc1f248aa`.
The complete GitHub commit diff has 2,395 changed files, **105 removed corpus files
and zero renamed files**; an independent parent/child Git tree comparison agrees.
The original [issue 6](https://github.com/sondreskarsten/norwegian-laws/issues/6)
count of 101 does not match this verified boundary.

The scope is this single pinned deletion commit, not every removed document in all
repository history. No copy was taken from the synthetic `law-history` branch.
These artifacts are not raw Lovdata XML, snapshot-v4 source observations, current
consolidated law, or reconstructed text for a legal date.

## Read or download

Each index row links to the preserved reader Markdown, its metadata record and an
immutable download of the same reader file at the original parent commit.
The Markdown bytes remain unchanged; all archive labels and provenance live in
the index and metadata, outside those original bytes. A copy's own old headings
or dates do not establish its present legal status.

Objects use `objects/sha256/<digest>.md`. Metadata lives under
`records/<exit-commit>/<original-path>.json` and records the original path, prior
commit, exit commit/time, Git blob, content hash and byte length. Future source
observations or legal determinations must be separate linked evidence; they must
not rewrite these copies or silently give their unknown dates inferred values.
